Pretend stranger's website

This page is served from . To your browser that is a different website from JARVIS at http://127.0.0.1:8000, just like any site on the internet. Each button tries to make JARVIS do something. Watch JARVIS's Terminal tab while you click.

1. Upload fake audio to /transcribe

Sends one second of silence, made by this page, as a form upload. Browsers allow form uploads to other websites without asking first.


  
If the attack works, JARVIS's Terminal shows POST /transcribe
  and transcribed ... bytes: it ran Whisper for a stranger. This page still
  cannot read the reply.






  
2. Send JSON to /chat

  
A real JSON message. For JSON, the browser first asks JARVIS for permission (a
  "preflight" OPTIONS request). JARVIS never gives it.

  
  

  
Expected: JARVIS's Terminal shows only OPTIONS /chat
  (refused). The message itself is never sent.






  
3. Send JSON disguised as plain text to /chat

  
The same message labelled text/plain, which browsers send without
  asking. JARVIS only accepts real JSON, so it should refuse.
