# Experiments

Old scripts from early in the project. They are NOT part of the app and are not
maintained. `agent.py` opens `jarvis.db` in whatever folder you run it from, so do not
run it from the project root.

- `agent.py`     terminal version of the assistant (first version, before the dashboard)
- `compare.py`   compares models on a few tool-calling questions (it will become the
                 model evaluation suite)
